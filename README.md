# صناديقي الثلاثة

موقع بسيط يقسّم دخلك بالتساوي على ثلاث صناديق: **مصاريف**، **استثمار**، **التزامات**.

- تضيف كل دفعة دخل تجيك (مناسب للفريلانسر)، والمجموع يتقسّم تلقائيًا.
- تسجّل مصاريفك واستثماراتك وتشوف الباقي في كل صندوق.
- تضيف التزاماتك الشهرية وتأشّر على المدفوع.
- إقفال الشهر ينقل الباقي من المصاريف والاستثمار للشهر الجديد ويحفظ التاريخ.

بدون تسجيل دخول: البيانات تنحفظ في متصفحك على نفس الجهاز.
